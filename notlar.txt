Linux Komutlari ve Aciklamalari

1. pwd: Bulundugum dizini gosterir.
2. ls: Dizin icindeki dosyalari listeler.
3. cd: Baska bir dizine gecmemizi saglar.
4. mkdir: Yeni bir dizin olusturur.
5. clear: Terminal ekranini temizler.
6. git status: Dosyalardaki değişikliklerin durumunu gösterir.
7. git add: Dosyaları staging alanına ekler.
8. git commit: Değişiklikleri kaydeder.
9. git log: Önceki commitleri gösterir.
10. git branch: Branch listesini gösterir.
11. git switch: Branchler arasinda gecis yapar.
